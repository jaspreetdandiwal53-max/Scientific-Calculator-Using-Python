SCIENTIFIC CALCULATOR GUI

Requirements:
- Python 3
- tkinter (usually included with Python)

How to run:
1. Open scientific_calculator_gui.py in IDLE or VS Code.
2. Run the file.
3. Click the buttons to enter calculations.
4. Click = to calculate or Clear to reset.

The window uses a blue background and clickable calculator buttons.
Scientific buttons include square root, square, sine, cosine, and logarithm.
Trigonometric angles are entered in degrees.
